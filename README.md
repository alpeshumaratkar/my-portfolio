# My Portfolio Website

## Overview

A full-stack personal portfolio website developed to showcase my skills, projects, education, and contact information.

The website allows visitors and recruiters to learn about my technical background and explore my projects through a clean and responsive user interface.

## Features

- Responsive Design
- About Me Section
- Skills Showcase
- Project Portfolio
- Contact Form
- Modern User Interface

- CSS3
- JavaScript

### Backend
- Node.js
